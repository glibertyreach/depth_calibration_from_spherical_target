# Figures for the calibration analysis

Each `make_fig_*.py` script writes the figure of the same name. Constants from the
XSearch+1UN/2UN specification (Draft 0.9, section 3.1) are indicative only and are
named at the top of each script.

    python3 docs/analysis/figures/make_fig_sphere_view_effects.py
    python3 docs/analysis/figures/make_fig_pose_grid_coverage.py
    python3 docs/analysis/figures/make_fig_spline_complexity.py
    python3 docs/analysis/figures/make_fig_sphere_radius_choice.py

Requirements: numpy, scipy, matplotlib.
